# EduFlow

Plataforma educativa SaaS demostrativa con catálogo público, acceso de estudiante, dashboard y seguimiento local del progreso.

> Este proyecto es una demostración para portafolio y no representa una empresa real.

## Tecnologías

- React 19 y React Router
- Vite
- CSS responsive propio
- Lucide React
- Fontsource (DM Sans y Plus Jakarta Sans)
- Playwright

## Funcionalidades

- Landing comercial y catálogo de ocho cursos.
- Búsqueda y categorías mediante parámetros de URL.
- Detalles con profesor, duración, temario y resultados esperados.
- Login local demostrativo.
- Dashboard de Carlos Mendoza con cursos, progreso, próximas clases y certificados.
- Reproductor de curso simulado con navegación entre lecciones.
- Lecciones completadas y progreso guardados en `localStorage`.
- Restablecimiento de los datos de demostración.
- Estados vacíos, rutas inexistentes y navegación protegida.
- Responsive para móvil, tablet y escritorio.
