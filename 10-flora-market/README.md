# Flora Market

Tienda artesanal demostrativa con una identidad lifestyle, catálogo de 20 productos y carrito persistente.

## Tecnologías

React, Vite, React Router, CSS moderno, Lucide React y `localStorage`.

## Funcionalidades

- Inicio editorial, catálogo filtrable y búsqueda.
- Cinco categorías y 20 productos con stock ficticio.
- Detalle dinámico de cada producto.
- Carrito lateral y página de canasta.
- Agregar, eliminar y cambiar cantidades.
- Subtotal, envío ficticio y total calculados en tiempo real.
- Checkout demostrativo sin pagos ni envío de datos.
- Diseño responsive para móvil, tablet y escritorio.

## Ejecutar

```bash
npm install
npm run dev
```

Abre `http://127.0.0.1:5182`.

## Datos demo

El carrito se guarda en `localStorage` con la clave `flora_cart`. No existen credenciales.

> Este proyecto es una demostración para portafolio y no representa una empresa real.
